    ❓ Règles du jeu

    1. Observation : Au début de chaque manche, un point devient jaune pendant quelques secondes.

    2. Suivi (Object Tracking) : Tous les points se mettent à bouger. Vous devez garder les yeux fixés sur le point initialement jaune.

    3. Stop : Appuyez sur le bouton STOP dès que vous le souhaitez pour figer les mouvements.

    4. Sélection : Cliquez sur le point que vous pensez être le bon. S'il s'illumine en vert, c'est gagné !
